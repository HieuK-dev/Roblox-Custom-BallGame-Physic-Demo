# Custom Physics & Rolling Mechanic Controller

A robust, physics-based character controller built for Roblox, designed to replace the default Humanoid mechanics with smooth, zero-delay interactions.

## 🛠️ Core Features
* **Custom Physics Engine:** Utilized `LinearVelocity` and `AngularVelocity` for fluid, physics-driven movement.
* **Zero Input Delay:** Handled Client-Server network ownership (`SetNetworkOwner`) to completely eliminate replication lag.
* **Dynamic State Management:** Real-time object scaling and mass calculation upon triggering external events (e.g., item collection).
* **Performance Optimized:** Disabled `PlatformStand` and unnecessary Humanoid states to ensure stable frame rates and server performance.
